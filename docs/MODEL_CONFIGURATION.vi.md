# Cấu hình model trong Egoric Studio

## API Key toàn cục

1. Mở **Cấu hình mô hình** từ dashboard hoặc thanh bên.
2. Chọn **Cấu hình chung**.
3. Nhập API Key của gateway đang dùng.
4. Nhấn **Xác thực và lưu**.

API Key được lưu cục bộ. Bạn có thể đặt Key riêng cho từng model nếu nhà cung cấp yêu cầu.

## Chọn model hoạt động

Egoric Studio chia model thành ba nhóm:

- **Hội thoại**: phân tích kịch bản, tạo storyboard và tối ưu prompt.
- **Hình ảnh**: tạo concept nhân vật, bối cảnh và keyframe.
- **Video**: tạo video đồng bộ, bất đồng bộ hoặc theo giao diện tác vụ Ark.

Nhấn **Sử dụng** trên thẻ model để đặt model hoạt động cho nhóm đó.

## Thêm model tùy chỉnh

1. Chọn nhóm model phù hợp.
2. Nhấn **Thêm model tùy chỉnh**.
3. Nhập tên hiển thị và chính xác giá trị `model` mà API mong đợi.
4. Điền endpoint và API Key riêng nếu cần.
5. Với video, chọn đúng chế độ đồng bộ, bất đồng bộ hoặc Doubao Ark.

## Dữ liệu và quyền riêng tư

Cấu hình model và API Key được lưu trong trình duyệt. Xóa dữ liệu trang web sẽ xóa cả cấu hình và dự án cục bộ; hãy xuất bản sao trước khi dọn bộ nhớ.
